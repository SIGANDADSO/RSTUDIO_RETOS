# 🧩 RSTUDIO_RETOS
Bienvenido a **Rstudio_Retos**, un espacio para guardar scripts en **R** para documentar, prácticar, consultar y aplicar en proyectos. 
---
## 📁 Descripción del repositorio
Este repositorio contiene scripts organizados por temáticas y niveles de dificultad. El objetivo es mantener una biblioteca de código reusable donde cualquiera pueda consultar cómo resolver problemas específicos en R. 
---
## 📚 Libros recomendados para aprender R
Si quieres aprender más sobre R y Data Science, te sugiero revisar estos libros gratuitos:
1. **[R for Data Science (2e)](https://r4ds.hadley.nz/)** *(Hadley Wickham, Mine Çetinkaya-Rundel & Garrett Grolemund)*: Este libro te enseñará a realizar ciencia de datos con R: aprenderás a importar tus datos a R, a estructurarlos de la forma más útil, a transformarlos y a visualizarlos en el ecosistema `tidyverse`.
2. **[Geographic Data Science with R: Visualizing and Analyzing Environmental Change](https://bookdown.org/mcwimberly/gdswr-book/)** *(Michael C. Wimberly)*: Excelente libro en línea para aprender manipulación, visualización y análisis de datos geoespaciales y ambientales utilizando `tidyverse`, `sf` y `terra` en R.
3. **[Hydroinformatics](https://vt-hydroinformatics.github.io/Quarto_Book/)** *(JP Gannon)*: Este libro es guía práctica sobre análisis de datos e hidrología en R, que abarca desde fundamentos de `tidyverse` y estadísticas básicas hasta datos geoespaciales, delimitación de cuencas e introducción a modelado hidrológico.

## 🚀 Cómo usar este repositorio

### 1. Clonar el repositorio
Abre tu terminal o consola de Git y ejecuta:

```bash
git clone https://github.com/SIGANDADSO/RSTUDIO_RETOS.git
```

### 2. Abrir en RStudio

1. Ve a la carpeta clonada en tu computadora o desde el mismo Rstudio lo puedes hacer.

2. Navega a la carpeta de tu interés.

3. Abre el archivo de script .R que desees probar.

4. Ejecuta el código línea por línea para ponerlo en práctica.
